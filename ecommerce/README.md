# Bem-Vindo ao Projeto Tools

## Sobre o projeto Tools:

O projeto Tools é um projeto acadêmico, livre de qualquer vínculo comercial, com o objetivo de ensinar jovens programadores a trabalhar com **HTML**, **CSS** e **JavaScript Puro**.

Este código é um código de referência que poderá ser adaptado para diferentes temas e abordagens, podendo ser simples ou complexo.

## Como executar:

1. Baixe os arquivos do projeto e descompacte-os.
2. Através da linha de comando, acesse a pasta do projeto.
3. Execute o comando `npm install`.
4. Depois de instaladas as dependências do projeto, execute o comando `npm run dev`.

## Dependências:
- **Vite**.
- **Xlsx** para exportação para o Excel.

## Base de Dados:
Para modificar ou cadastrar novos produtos, acesse o arquivo `database.js`. Para incluir um produto, copie o objeto anterior e modifique somente as informações necessárias.

## CSS:
As regras CSS estão organizadas conforme página e estrutura. O arquivo `styles.css` é utilizado para centralizar as regras e referências únicas.
